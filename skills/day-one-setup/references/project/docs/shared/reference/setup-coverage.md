# Setup coverage

Both routes use the same capability recipes. AI-assisted setup adds client
bootstrap, planning, approved execution and evidence review. Manual setup
requires no Day One Mac scripts. Optional utilities have independent prerequisites.

| Capability | Canonical manual recipe | Verification |
|---|---|---|
| Starting point and backup | [macOS](../../setup/manual/macos.md), [backup](../../setup/manual/backup-and-restore.md) | Supported device, policy and readable restored sample |
| AI bootstrap and gateway choice | [client preparation](../../setup/manual/ai/setup-assistant.md), [OmniRoute](../../setup/manual/ai/omniroute.md) | Client response and selected execution probe |
| Apple tools and packages | [Homebrew](../../setup/manual/homebrew.md) | Native package tools and approved owner |
| Authentication | [Security](../../setup/manual/security/README.md) | Chosen identity and recoverable account access |
| Git and hosting | [Git](../../setup/manual/git/setup.md) | Correct identity and authorised repository access |
| Shell and configuration | [Shell](../../setup/manual/shell/README.md) | Syntax and behaviour in a new shell |
| Languages | [Toolchains](../../setup/manual/languages.md) | Selected project runtime and dependency checks |
| Editors and applications | [Applications](../../setup/manual/apps/README.md), [VS Code](../../setup/manual/editors/vscode.md) | App launch and intended profile/configuration |
| Databases | [Databases](../../setup/manual/databases/README.md) | Chosen environment, query and restore checks |
| Skills, agents and MCP | [Skills](../../setup/manual/ai/day-one-skills.md), [MCP](../../setup/manual/ai/mcp.md) | Discovery, scope and harmless tool call |
| Maintenance and removal | [Lifecycle](../../setup/manual/lifecycle.md) | Scoped change and functional recheck |

[AI journey](../../setup/ai/README.md), [manual journey](../../setup/manual/README.md)
and [reviewed tools](tools.md) identify who performs each operation. Human
account, licence, permission and recovery actions remain explicit.
