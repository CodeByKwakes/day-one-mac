# Prepare an existing Mac

Keep the working system intact while deciding what to change. Neither setup
route erases the disk or requires reinstalling macOS.

1. Identify whether this is a personal or organisation-managed Mac.

   Expected result: known installation permissions and any organisation policy.
   Read [prerequisites](../../prerequisites.md) before making changes.

2. Record installed tools and their owners using the
   [inventory guide](../../../setup/manual/backup-and-restore.md).

   Expected result: a private inventory that distinguishes existing tools from
   requested additions. Do not publish account or company details.

3. Check your backup and restoration procedure using
   [backup readiness](../../../setup/manual/backup-and-restore.md).

   Expected result: a recent backup and evidence that a sample can be restored.

4. Choose [AI-assisted](../../../setup/ai/README.md) or
   [manual setup](../../../setup/manual/README.md).

   Expected result: one route and a list of missing capabilities. Reuse working
   software and configuration; review conflicts individually.

## Recovery

If an inventory or check fails, keep the existing system and repair that check
before changing the affected component. Former broad cleanup and setup-runner
commands are retired; see [migration](../../migration/from-scripted-setup.md).
