engineering decisions and evidence for people changing Day One Mac.

| Understand historical runtime acceptance | [Historical acceptance](acceptance/ACCEPTANCE.md) |
| Follow branch and release procedures | [Git workflow](contributing/GIT-WORKFLOW.md) |

resolution notes distinguishable. They are not current user procedures and are
not included in installed skill packages.
