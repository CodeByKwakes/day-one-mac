# Maintainer guide

User setup starts in [Start Here](../docs/START-HERE.md). This directory holds
engineering decisions and evidence for people changing Day One Mac.

| Work | Read |
| --- | --- |

| Review the implementation contract and results | [Restructure plan](plans/2026-10-19-restructure.md) |
| Review the independent findings | [Restructure review](audits/RESTRUCTURE-DIFFERENTIAL-REVIEW-2026-10-19.md) |
| Review the proposed Second Brain skill and repository connections | [Second Brain proposal](plans/2026-10-25-second-brain-skill.md) |
| Set up local checks and hooks | [Contributor tooling](contributing/CONTRIBUTOR-TOOLING.md) |
| Prepare a release and understand acceptance limits | [Acceptance](acceptance/ACCEPTANCE.md) |
| Follow branch and release procedures | [Git workflow](contributing/GIT-WORKFLOW.md) |

Dated audits describe the state examined at that time. Keep their findings and
resolution notes distinguishable. They are not current user procedures and are
not included in installed skill packages.
