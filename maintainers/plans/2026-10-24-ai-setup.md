# Early AI setup and manual coverage implementation plan

> For agentic workers: use executing-plans to implement and verify these tasks inline. The approved audit and amended checkpoint design below define the scope.

**Goal:** Offer optional AI assistance before Phase 1 and repair the audited manual procedures.

**Architecture:** A separate optional checkpoint reuses state and operation-lock helpers without changing required phase dependencies. A small catalogue owns client executable and installer metadata. Manual guidance owns client sign-in and permission checks; the assisted command prepares a private handoff and never starts an agent with elevated permissions.

**Tech stack:** macOS Bash 3.2, existing Node documentation checks, Markdown and TSV catalogues.

**Spec:** The user approved the documentation audit and then approved an optional pre-Phase-1 choice: no AI, guidance only, or approved local execution. Reuse or install one client, preserve its owner, verify it, and retain Module 10 for later expansion. Preserve all previously approved documentation repairs and add a reusable setup skill.

## Global constraints

- Preserve phase IDs 01-08, Stage 0 and retired Module 12.
- Manual setup invokes no Day One Mac scripts.
- Preview and check do not write state or download/install software.
- No live installation, credentials, commit, push or public release is part of this change.
- Keep required setup usable when AI is unavailable or skipped.
- Preserve existing client configuration and package ownership.
- Sign-in, permissions, licences and recovery verification stay manual.
- Keep all public examples portable; include new runtime files in the allowlist.

## Review focus

- A fresh Mac lacks Homebrew, Node and saved setup state: use native prerequisites only.
- A saved assistant or installer is missing, changed or unsafe: preserve it and report the exact next step.
- An existing native client must not acquire a second Homebrew owner through Module 10.
- Failed downloads, cancelled installation and interrupted handoff creation must never produce successful readiness evidence.
- Backup, restore and symlink examples must preserve originals and fail visibly.
