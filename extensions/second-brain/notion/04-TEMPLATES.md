# 4 — Database templates

[← Databases](03-DATABASES-AND-PROPERTIES.md) · [Dashboard →](05-DASHBOARD.md)

## Purpose

Templates remove blank-page decisions and apply safe defaults. Create these
inside the Knowledge database by opening the **New** menu and choosing **New
template**.

## Quick Capture

Defaults: Type = Capture, Status = Inbox, AI Allowed = off.

```text
What did I capture?

Why might it matter?

Source or context

Next decision
```

Keep this template short enough to use from a phone.

## Development Note

Defaults: Type = Development Note, Status = Inbox, AI Allowed = off.

```text
Problem

Context and constraints

What I tried

Solution

Why it works

Commands or code

Follow-up actions
```

## Software Content

Defaults: Type = Content, Status = Inbox.

```text
Audience

Problem or promise

Outline

Code or demonstration

Evidence and sources

Call to action

Publication checklist
```

## Tech Content

Defaults: Type = Content, Status = Inbox.

```text
Audience

Angle

Key claims

Research and sources

Script or outline

Visuals

Publication checklist
```

## Source

Create this in Sources, not Knowledge.

```text
Summary in my own words

Important claims

Evidence quality

What this changes

Possible uses

Verification notes
```

## Project

Create this in Projects.

```text
Outcome

Why this matters

Scope

Next action

Risks and decisions

Definition of done
```

## Person

Defaults: Type = Person, Status = Active, Sensitivity = Personal.

```text
Context

Topics and interests

Last meaningful interaction

Follow-up
```

Do not store secrets or unnecessary sensitive personal data.

## Weekly Review

Defaults: Type = Review, Status = Active, AI Allowed = off.

```text
Inbox processed

Active projects reviewed

Sources verified

Content moved forward

AI suggestions reviewed

Stale knowledge found

What I learned

Focus for next week
```

## Template safety rules

- Leave AI Allowed off by default.
- Do not force a Domain in a generic capture template.
- Use conservative Sensitivity defaults.
- Never place credentials or private keys in a template.
- Test every template with one disposable page.
