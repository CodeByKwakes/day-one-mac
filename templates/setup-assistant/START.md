# Start an assistant session

1. Read docs/setup/ai/bootstrap.md and verify one client and provider connection.
2. Review AGENTS.md, the six skills and your client role definitions.
3. Open this directory in the selected client. Read the client guide under
   docs/setup/ai/clients/ before choosing permissions.
4. Ask for a plan: "Use day-one-setup to inspect my Mac and propose the selected
   capabilities. Do not change anything yet. Offer the OmniRoute choices."
5. Review the proposed commands, recovery and human steps. Approve the desired
   scope explicitly, then run the operator with normal client confirmations.
6. Ask the verifier to review the results. Save authorized notes under session/.

No account, provider, MCP server or global client setting was configured by
exporting this workspace. A new export is the update mechanism. Keep the old
workspace until you have compared changes and preserved private notes.
