# Day One Mac setup workspace

Read docs/START-HERE.md, docs/setup/ai/operation.md and the relevant manual
recipe before proposing a change. This workspace contains reviewed reference
material; it is not an instruction to install everything.

Establish guidance-only or approved execution mode, requested capabilities and
existing owners. Reuse prior user choices. Offer direct provider access,
existing OmniRoute, local OmniRoute or gateway setup later before relying on AI.

Plan with exact commands, affected paths, prerequisites and recovery. Execute
only approved scope using client permission controls. Never invoke the retired
setup runner, erase disks, adopt foreign resources or expose credentials.
Read-only roles may inspect evidence; they cannot grant themselves write access.

Use .agents/skills/day-one-* for setup, checking, maintenance, recovery,
OmniRoute and repository contribution. Client-specific agent definitions are
in their native project directories. Their permissions differ; read the client
guide. Keep only one operator writing a given configuration at a time.

Keep authorized private notes in session/. Record intent separately from
observed checks, including versions, results, unresolved human steps and backup
locations. Do not store passwords, tokens or private key contents in notes.
Recheck the machine when resuming. Existing phase markers are historical data.
